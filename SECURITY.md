# Security Policy

## Supported Versions
Only the latest version of Havana is supported for security updates.

## Reporting a Vulnerability
We take the security of Havana seriously. If you believe you have found a security vulnerability, please report it to us by emailing `security@havana-wallet.org`.

**Please do not open a public GitHub issue for security vulnerabilities.**

### What to include:
- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact of the vulnerability.

We will acknowledge your report within 48 hours and work with you to resolve the issue as quickly as possible.
