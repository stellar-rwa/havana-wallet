# Havana Architecture

## Overview
Havana is a decentralized financial identity and payment platform built on the Stellar blockchain.

## Tech Stack
- Frontend: Next.js 16 (App Router), Tailwind CSS 4, Zustand, TanStack Query.
- Backend: Express 5, Prisma 6, PostgreSQL.
- Contracts: Soroban (Rust), Protocol 25 ZK Primitives.

## Core Flows
1. Identity Onboarding (ZK-Proofs)
2. NGO Disbursements (SDP)
3. Payroll Escrow (Smart Contracts)
4. Merchant Payments (USDC)
